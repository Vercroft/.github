# Contributing

This is the default contribution guide for every Vercroft repository that has none of its own.

## What we welcome

- **Issues:** bug reports, ideas and translations. Search the open issues first, and include what you expected, what
  happened, and how to reproduce it.
- **Discussions,** where a repository has them switched on: questions and ideas that are not yet an issue.

## Pull requests

Our products, business sites and SDKs take no outside code: their pull requests are limited to collaborators, so please
open an issue instead. Everyone can still read and comment on the pull requests that are open.

## Security

Never report a vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md).

## How we work

Every repository follows [Engineering Practices](https://github.com/Vercroft/engineering-practices), written down in its
[STANDARD.md](https://github.com/Vercroft/engineering-practices/blob/main/STANDARD.md). The contribution rules are its
section 7F.4.
